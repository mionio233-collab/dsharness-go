在的，我说一下我能帮你做什么 👋

写代码 / 做页面

  • 写前端页面、HTML/CSS/JS 小组件，默认按手机屏幕尺寸来做
  • 写脚本、改 bug、解释代码、做小工具
  • 可以直接把文件写入工作区，方便你查看或拿去用

做 DSH Go 手机插件

  • 生成插件 JSON 包（主题配色、背景图、桌面宠物、自定义指令文本）
  • 你会拿到一个 <id>.dshgo.json，自己在 App 的「插件 → 创建/安装」里预览并安装
  • 说明一下：我只能生成文件，不会自动装上、也不会上架

查资料 / 处理文字

  • 读取你给的文本文件、抓取网页内容做整理总结
  • 翻译、润色、写文案、列大纲、做计划

画图

  • 用本机图片模型生成插画/图标（提示词得用英文，我会帮你翻译）

做不了的事

  • 不能联网装软件、不能访问你手机里的相册/通讯录、不能替你在 App 里点安装。

Connect to desktop: install the DSH Go bridge

Install the bridge plugin in desktop DeepSeek Harness, then continue workspaces, sessions and tasks from your phone over LAN or the same account.

One-click install

Search for dsh-go-workspace in the DSH plugin page, or run:

dsh plugin --profile web add dsh-go-workspace

In DSH Desktop, use the in-app plugin page; the CLI command is for the web profile.

How to connect

  1. Install and enable DSH Go-workspace
  2. Open DSHarness Go bridge and enable LAN access
  3. Generate pairing information or a QR code on desktop
  4. On the phone open Settings → Connection and scan or pair

FAQ

Do I need a computer?

No. The app works with your own API providers or local GGUF models offline; connect to desktop Harness when you want to continue desktop sessions.

Do I need Ubuntu or an emulator on Android?

No. DSHarness Go is a native Android app that uses system APIs directly. No Linux emulator and no root required.

When is iOS coming?

iOS 版本仍在开发中，Not available yet。发布后会在Download页和 GitHub Releases 公布。

Is the source code public?

The source is currently private and only signed APKs are distributed. After the iOS release, the Android and iOS sources will be open-sourced together.
