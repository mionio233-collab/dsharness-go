在的，我说一下我能帮你做什么 👋

写代码 / 做页面

  • 写前端页面、HTML/CSS/JS 小组件，默认按手机屏幕尺寸来做
  • 写脚本、改 bug、解释代码、做小工具
  • 可以直接把文件写入工作区，方便你查看或拿去用

做 DSH Go 手机插件

  • 生成插件 JSON 包（主题配色、背景图、桌面宠物、自定义指令文本）
  • 你会拿到一个 <id>.dshgo.json，自己在 App 的「插件 → 创建/安装」里预览并安装
  • 说明一下：我只能生成文件，不会自动装上、也不会上架

查资料 / 处理文字

  • 读取你给的文本文件、抓取网页内容做整理总结
  • 翻译、润色、写文案、列大纲、做计划

画图

  • 用本机图片模型生成插画/图标（提示词得用英文，我会帮你翻译）

做不了的事

  • 不能联网装软件、不能访问你手机里的相册/通讯录、不能替你在 App 里点安装。

一个 App，两种用法

连接电脑，或在手机上独立运行。随时切换，无需重装。

远程连接

电脑端启用互联插件，扫码或同账号配对。手机端继续桌面对话、回答电脑端的提问卡片，模型与项目上下文保持一致。

局域网 / 中继断线重连增量同步

手机独立运行

不依赖电脑。配置自己的 API 供应商，或下载离线模型；生图与自动化都在手机上完成，无需 Ubuntu 模拟器、无需 root。

连接电脑：安装 DSH Go 互联插件

在电脑端 DeepSeek Harness 安装互联插件，手机即可通过局域网或同账号继续工作区、会话和任务。

一键安装

在 DSH 插件页搜索 dsh-go-workspace 即可一键安装；命令行用户也可以直接运行：

dsh plugin --profile web add dsh-go-workspace

DSH Desktop 请使用应用内插件页安装，命令行方式适用于 Web profile。

连接步骤

  1. 安装并启用 DSH Go-workspace
  2. 打开 DSHarness Go 互联插件，开启局域网访问
  3. 在电脑端生成配对信息 / 二维码
  4. 手机「设置 → 连接」扫码或同账号配对

常见问题

需要电脑才能用吗？

不需要。手机端可以独立使用自有 API 供应商，也可以下载本地 GGUF 模型离线推理；想继续电脑上的会话时，再连接电脑端 Harness。

需要在 Android 上安装 Ubuntu / 模拟器吗？

不需要。DSHarness Go 是原生 Android 应用，直接调用系统能力，无需 Linux 模拟器、无需 root。

iOS 版本什么时候发布？

iOS 版本仍在开发中，暂不提供下载。发布后会在下载页和 GitHub Releases 公布。

源码是否公开？

Android 源码已在 GitHub 公开，采用 AGPL-3.0；可在仓库中浏览代码和构建文档。
